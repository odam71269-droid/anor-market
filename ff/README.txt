
# AnorMarket — yaxshilangan versiya

**Nimalar qilindi:**
- Barcha sahifalarda yagona header, autentifikatsiya (kirish/ro‘yxatdan o‘tish) va UX.
- Savatcha (localStorage) — tovar qo‘shish, o‘chirish, jami summani hisoblash.
- `app.js` — umumiy autentifikatsiya va savatcha mantiqlari.
- `menyu.html` ichidagi noto‘g‘ri rasm URL’lari tuzatildi (`hhttps` → `https` va butkul buzilgan URL almashtirildi).
- `login.html` va `registor.html` sahifalaridagi xatolar tuzatildi (tugma ishlashi, nomlar, JS).
- Moslashuvchan dizayn, yaxshilangan accessibility (alt, aria), toza layout.
- `top tovarlar.html` — savatchaga qo‘shish tugmasi endi real ishlaydi.

**Fayllar:**
- `index.html` — kirish sahifasi + VIP bo‘lim
- `menyu.html` — asosiy katalog va e’lonlar
- `top tovarlar.html` — mahsulotlar grid
- `cart.html` — savatcha
- `app.js` — umumiy JS
- `menyu.css`, `styles.css`, `style.css` — mavjud uslublar (saqlab qolindi)

**Ishga tushirish:**
Fayllarni bir papkada oching va `index.html`ni brauzerda ishga tushiring.
